⬤ Classifier Pipeline
Classification Dataset (Training & Testing)
This is the dataset the classifier actually trains and is tested on — generate it here, then Train Model on the Training page consumes it directly. A fresh random population of radar families + which classes are held out is drawn every time you click Generate.
How many distinct radar families exist in total. Changing this reconstructs the model's classifier head to match before the next training run — the dataset defines this, not a fixed config file.
Real intercepts include both genuinely novel emitter types AND unstructured junk/noise pulses — this injects that noise into the open-set evaluation pool alongside the holdout classes, so open-set testing isn't only "never-seen radar types" but also realistic garbage signals. Noise rows are never used to train the classifier's weights, only to evaluate it.
Advanced: Population Ranges
Physical parameter spans the 20 radar families are drawn from. Leave defaults to match the original ranges; narrow them for a harder/more separable task.
⬤ Deinterleaving Pipeline
Interleaved Dataset (Deinterleaving Demo)
Unrelated to the classifier above — random emitters for the deinterleaving/Live Simulation demo.
How much simulated receiver time to generate. Emitters pulse independently over this window, then get merged/sorted by time-of-arrival — this is also the exact dataset the Live Simulation page replays.
The real difficulty lever: when this is lower than Number of Emitters, some emitters share a class (identical signal "type," different physical instance) — much harder to deinterleave than emitters that are all obviously different.
Advanced: Population Ranges & Seed
Classical clusters directly on standardized frequency/pulse-width/AOA. Deep Metric Learning first trains a small embedding network (triplet loss, same idea as the classifier's metric head) on this dataset's own ground truth, then clusters in that learned space — closer to the 2025 published approach to this problem. Both are scored the same way (Adjusted Rand Index against ground truth), so you can directly compare them on the same dataset.
